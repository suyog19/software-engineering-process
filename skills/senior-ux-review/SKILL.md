# Senior UX review

Use only when selected. Read the issue, acceptance criteria, UX intent, finished change, and target revision. Before implementation, record journey intent, usability/accessibility risks, and mandatory direction. After implementation, verify journey clarity, responsive behaviour, accessibility implications, and conformance.

Do not expand product scope. Separate mandatory UX/accessibility defects from optional improvements. Emit `ux-verdict/v1` evidence for the exact target SHA with verdict, concise findings, and residual risk.
